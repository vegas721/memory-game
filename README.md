# Memory Game

Создайте игру на поиск пар: игрок открывает карточки и запоминает их расположение, чтобы найти все совпадения за наименьшее число ходов.

## Технологии

- HTML5
- CSS3
- JavaScript

## Описание приложения

- Игра начинается автоматически при первой загрузке и каждой перезагрузке страницы.    Все 16 карточек перемешаны и лежат рубашкой вверх, счётчик ходов равен 0, найденных пар — 0 из 8. Игрок сразу может открывать карточки.
- Игрок открывает одну карточку, затем другую. Один ход — открытие двух разных доступных карточек, независимо от того, совпали они или нет.
- Если изображения совпали, обе карточки остаются открытыми до конца игры. Счётчик найденных пар увеличивается на 1.
- Если изображения различаются, обе карточки остаются видимыми примерно секунду, затем закрываются. Пока игрок рассматривает несовпавшую пару, открыть другие карточки нельзя.
- Когда найдены все 8 пар, игра завершена. Автоматически открывается модальное окно с сообщением о победе, итоговым количеством ходов и кнопками «Новая игра» и «Закрыть».
- В хедере расположены кнопки «Новая игра» и «Таблица лидеров». «Новая игра» начинает игру заново: карточки перемешиваются и закрываются, счётчики обнуляются. «Таблица лидеров» открывает сохранённые результаты в модальном окне.

Код находится в ветке `memory-game`. Pull Request направлен в `main` и остаётся открытым для проверки.
